# Study 03: single-trait parameter estimation

This study validates posterior extraction and recovery of six common estimands
for four single-trait BED/CSR BayesC/BayesR workflows. It distinguishes
generating parameters from finite-sample realized quantities and labels matched
and misspecified prior–architecture combinations. The development benchmark has
one replicate and one short chain; it does not establish bias, interval
calibration, convergence, or method rankings.

Run the contract smoke test first, then `run_parameter_estimation_benchmark.R`.
Study 04 will separately address multichain convergence and MCMC-length choice.
